# How to get your Corelyn API key to use in code

First go  to the [Corelyn Cloud](https://corelyn.github.io/cloud/) and login
with your google acount.

Click the button with "Generate my key" and wait for a bit, then click the copy button and keep your key somewhere safe, do not share this key.

> You can continue to the next tab
> **WARNING :** API keys may be deleated monthly or on maintance
